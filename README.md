# The Game of Control

A cinematic, hand-drawn literature-review presentation for a Game Theory course: six papers on how game theory can keep humans in control of AI, ending with the main paper, **The Oversight Game** (Overman & Bayati, ICML 2026).

Presented by Rachit Gupta · 24 November 2026.

## Run it

It's a single self-contained `index.html` (fonts embedded, no build step). Open it in a browser, or deploy the repo as a static site (e.g. Vercel, framework preset "Other").

Controls: `→` / click to advance (scenes build in steps) · `←` back · `F` fullscreen.

## Papers reviewed

All facts and figures in the slides are paraphrased from these papers. The narrative framing, analogies and drawings are the presenter's own.

1. Gruetzemacher, Avin, Fox & Saeri. *Strategic insights from simulation gaming of AI race dynamics.* Futures 167 (2025).
2. Conitzer & Oesterheld. *Foundations of Cooperative AI.* AAAI 2023.
3. Zhang, Yue & Fang. *A Game-Theoretic Framework for AI Governance.* arXiv:2305.14865 (2023).
4. Laufer, Kleinberg & Heidari. *The backfiring effect of weak AI safety regulation.* PNAS 123(30) (2026).
5. Kim, Choo, Neoh & Tambe. *Incentive-Aware AI Safety via Strategic Resource Allocation: A Stackelberg Security Games Perspective.* AAMAS 2026.
6. Overman & Bayati. *The Oversight Game: Learning to Cooperatively Balance an AI Agent's Safety and Autonomy.* ICML 2026.
